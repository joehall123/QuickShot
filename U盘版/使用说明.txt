QuickShot 截图工具 1.4 —— U 盘便携版
================================================

【怎么用】
1. 把「U盘版」这个文件夹整个拷到 U 盘里
2. 双击 QuickShot.exe 启动
3. 启动后：屏幕右侧出现一个蓝色悬浮球，右下角托盘出现相机图标
4. 截全屏：按 Ctrl+Alt+A，或者用鼠标左键点一下悬浮球
5. 截区域 / 窗口：按 Ctrl+Alt+S，进入取景框后拖框或单击窗口
6. 截图自动保存到本文件夹下的「验证截图」目录，不用再做任何设置
7. 每张图存好后，悬浮球和右下角托盘图标会一起由蓝变红 0.2 秒再回到蓝色 —— 看到变色就说明这张已经存下来了


【区域 / 窗口截图怎么用】
按 Ctrl+Alt+S 后画面会先定住并变暗，屏幕顶部有一行操作提示：
  按住左键拖框     = 只截框住的那一块，框边显示宽 x 高，松手就存好
  左键单击不拖动   = 直接截鼠标所在的那个窗口（含标题栏）
  按 W             = 开关「窗口吸附」，打开后鼠标指到哪就自动框住哪个窗口
  按 F             = 不框选，按整屏存
  按 Enter         = 存当前选区；没选区就按整屏存
  按 Esc 或按右键 = 取消，不存任何文件

存好后右下角会浮出一张缩略图，约 3 秒自动消失；点它可以直接打开
截图所在的文件夹，并选中刚存的那张图。与此同时悬浮球和托盘图标会闪一下红色（约 0.2 秒），
这是「已存盘」的即时信号，连拍的时候不用去点气泡也能确认。


【选 32 位还是 64 位】
QuickShot.exe       = 64 位，绝大多数电脑用这个
QuickShot_x86.exe   = 32 位，老机器 / 32 位 Win7 用这个

不确定的话先双击 QuickShot.exe；如果弹出「不是有效的 Win32 应用程序」，
说明系统是 32 位，改用 QuickShot_x86.exe 即可。
查看方法：右键「计算机」→ 属性 → 看「系统类型」。


【截图存在哪】
本文件夹\验证截图\Screenshot_20261103_213500.png

换到别的电脑上、盘符从 E: 变成 F: 都不影响 ——
配置里保存的是相对路径，不是固定盘符。
文件名前缀、PNG/JPEG/BMP 格式可以在「设置…」里改。


【悬浮球操作】
左键单击           = 立即截全屏
Shift + 左键单击   = 进入区域 / 窗口截图
左键拖动           = 挪位置（松手自动贴边，位置会记住）
右键单击           = 菜单：全屏截图 / 区域截图 / 保存位置 / 新建文件夹 / 设置 / 退出


【新建文件夹分类存放】
右键悬浮球（或右下角托盘图标）→ 新建文件夹…（自己命名）
弹出的小窗口里直接输入名字，例如「现场A」，按回车即可。

窗口里能看到这个文件夹的完整路径，边打字边变，不用猜存到哪去了。
如果名字和已有的文件夹重名，会问你要不要直接切过去，不会建出「现场A(2)」。

建好后自动切换过去，之后的截图都存进这个文件夹。
下次启动仍然停在最后用的那个文件夹。


【文件说明】
QuickShot.exe        主程序（64 位）
QuickShot_x86.exe    主程序（32 位）
使用说明.txt          本文件
quickshot.ini        配置文件，首次运行自动生成，不要手改也行
验证截图\            截图目录，首次运行自动创建


【注意事项】
- U 盘版不支持「开机自启」（盘符会变），设置里那一项是灰的，属于正常现象。
- 整个程序不写注册表、不写「我的文档」、不装任何东西。
  不要了直接删掉这个文件夹就干净了。
- 区域截图用的是定住的那一帧画面，取景期间屏幕上新冒出来的东西不会进图里；
  要抓实时变化的画面，请用 Ctrl+Alt+A 全屏截图。
- 如果 Win7 提示缺少 api-ms-win-crt-*.dll：
  装一下 Windows 补丁 KB2999226，或者用源码里的 build_msvc.bat
  在 VS2017 里重新编译一次（静态链接，不再依赖任何运行库）。
- 真正独占全屏的 DirectX 游戏，悬浮球和取景框都盖不住（这类窗口无法被普通程序覆盖）；
  浏览器 F11、PPT 放映、视频播放器、监控软件全屏都能正常显示。


【快捷键被占用】
如果启动时提示快捷键注册失败（比如和 QQ 的 Ctrl+Alt+A 撞了），
右键托盘图标或悬浮球 → 设置… → 分别点「全屏截图」或「区域截图」输入框 →
直接按下新组合键 → 确定。两个快捷键记得设成不一样的。
